HITech-AI 是"智启新航"AI 研学社的 GitHub 开源组织。社团以**朋辈互助与 AI 研学**为核心，帮助成员正确认识、合理使用人工智能，共同探索 AI 时代下的成长方向。

## 门面项目 · HIT-CampusAI

面向哈尔滨工业大学（本部、深圳、威海）师生的一站式校园 AI 生活助手：问办事流程、查图书馆借阅规则、看食堂营业时间，一句自然语言就能得到带知识库出处的回答。当前已落地深圳校区知识库，欢迎威海等校区同学参与建设。技术上用 FAISS 做向量检索，再由国产多模态大模型组织回答（RAG）。

项目完全开源（MIT），欢迎对 AI 应用、大模型、产品与校园服务感兴趣的同学参与建设。前往 [`HIT-CampusAI`](https://github.com/HITech-AI/HIT-CampusAI)。
